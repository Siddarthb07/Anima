## 2. Field and Summary of the Invention

The invention relates to reliability monitoring for text generated by large language models (LLMs). It addresses the problem of detecting, **during generation and before output is returned to a user**, when a model's output is likely to be unreliable (e.g., hallucinated or overconfident), by monitoring the model's **internal hidden-state activations** rather than relying solely on analysis of the finished output text.

A full technical description of the system, its four constituent mechanisms, and my preliminary identification of the closest prior art is set out in the attached **Invention Disclosure (Annex A)** and **Prior Art References (Annex B)**.

**In summary**, the system attaches trained probe networks to multiple layers of a transformer model via forward hooks, and applies four mechanisms to the resulting per-token readouts:

1. **Early-vs-late layer disagreement detection** (same probe head, two layers)
2. **Rolling-window temporal stability scoring** (8-token default window)
3. **Calibrated multi-signal fusion** driving an abstention decision (fused uncertainty + probe uncertainty + lexical hedging)
4. **Conditional corrective activation steering** (one-step residual correction on detected valence swings)

Supporting subsystems (not individually claimed): auxiliary uncertainty fusion from logits/attention entropy; Platt calibration; random-direction causal validation controls.

## 3. My Own Preliminary View on Claim Scope

I believe each of the four mechanisms above is, **individually**, close to existing published techniques, and I have identified specific prior art for each in Annex B. My tentative (non-expert) view is that only the **specific combination of all four mechanisms**, operating together as one real-time gating pipeline and applied through an **affect-style (valence/arousal/uncertainty) probe framing** rather than a truthfulness-style classifier, might be narrow enough to be non-obvious.

The closest combination prior art I have identified is **MERA** (Hedstrom et al., ICML 2025), which combines abstention with adaptive steering but uses a helper model and does not include layer-disagreement or temporal stability scoring in an affect-probe framing. Please test this differentiation independently — I understand MERA may substantially narrow or eliminate combination claim scope.

**Implementation note for claim drafting:** The four mechanisms share probe/hook infrastructure but are not all fused into a single abstention score. Guard abstention uses fused/probe uncertainty + lexical hedging; layer-disagreement and stability are parallel outputs (stability relabels regions only when `guard_mode="gate"`). Claims should describe the **system combination**, not a single fused voting function.

I am asking you to test this view through your own prior art search, **not to take it as established**. If your assessment is that this does not clear the bar for patentability, I would prefer to know that clearly and **not proceed to filing**.
