# Abstract (IEEE target: single paragraph, ≤250 words)

Trust interfaces for language-model tools often display green “safe” or “calibrated” badges after passing synthetic or fixture checks. We study whether such badges remain honest when the same scoring pipeline is evaluated on **live claim-encode** rows from public HaluEval and TruthfulQA. We introduce **Anima**, an open instrumentation stack that attaches valence, arousal, and uncertainty probes to Hugging Face causal language models, and a **Trust Integrity Gate** that seals a binary `trust_ui_claim_allowed` bit from multi-criteria live evaluation. On two locked instruction models (Qwen2.5-0.5B-Instruct and TinyLlama-1.1B-Chat), fixture Protocol F yields AUROC 1.00 while baseline Protocol L collapses (e.g., Qwen–HaluEval AUROC 0.25 with never-abstain and anti-aligned ranking), so GreenShieldBench correctly **denies** unlock. A separately named Protocol L′ LOQO ridge adaptation restores primary-suite AUROC (Qwen–HaluEval 0.92) and unlocks adapted receipts without silent production label flips. Matched semantic-entropy controls on the same rows do not overturn the baseline failure. A real Narratives fMRI depth check shows stimulus encoding ceilings (word-rate max *r* up to ~0.67) while PCA→valence holdout remains near zero—encoding interest without emotion–brain claims. Anima releases code, sealed receipts, and a dashboard that refuses green trust language without a sealed unlock.
